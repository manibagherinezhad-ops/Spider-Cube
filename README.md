# 🕷️ Spider Cube

> An interactive 3D image cube built with **HTML & CSS**, featuring a rotating cube effect triggered by hovering over the object.

---

## 🖤 About The Project

**Spider Cube** is a front-end practice project created to explore **3D visual effects, image positioning, CSS transformations, and hover interactions**.

The project features a three-dimensional cube with different images displayed across its faces. When the user hovers over the cube, the entire object rotates, revealing different viewing angles and creating an interactive visual experience.

The main focus is on using CSS to create the illusion of depth and movement while keeping the implementation centered around HTML and CSS.

Spider Cube is a small visual experiment that turns a collection of images into an interactive 3D object.

## 🌀 How It Works

The central element of Spider Cube is a three-dimensional cube made up of image-based faces.

Each face displays a different image, and the faces are arranged to form a single cube-like object.

When the user hovers over the cube, a CSS hover interaction changes its rotation. This allows the entire object to move as one 3D composition rather than rotating each image independently.

The overall effect relies on the relationship between the cube's faces, their positioning, and the rotation applied to the main object.

## 🎨 Design Direction

Spider Cube focuses on a simple but engaging visual idea: a cube built from images that responds to user interaction.

Instead of using a conventional image gallery, the project brings the images together inside a three-dimensional composition.

The rotation adds movement to the design and lets the user experience the cube from different angles.

The result is a compact front-end experiment centered around **3D structure, imagery, and CSS interaction**.
